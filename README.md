# QaaS Shampoo

- [Developer Shampoo](Developer%20Shampoo/README.md): exams, answers, and the interactive ecosystem graph.
- [Contributor Shampoo](Contributor%20Shampoo/README.md): contributor architecture, standards, and delivery guides.

Clone or download and extract the whole repository. Keep its directory structure intact. Read Markdown files in a Markdown viewer.

To run the graph, start a local server from this repository root:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Open <http://127.0.0.1:8000/Developer%20Shampoo/qaas-ecosystem/qaas-ecosystem.html>. Keep the server running while exploring. GitHub displays HTML source rather than running the graph. External documentation and source references require internet access.
